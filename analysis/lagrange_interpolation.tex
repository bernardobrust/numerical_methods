\section{Theoretical Development}\label{sec:intro}

Lagrange's Polynomial Interpolation is a method for aproximating unknown (continuous) functions with some known points using algebraic polynomials. This is possible due to Weierstrass Approximation Theorem:

\begin{theorem*}
  Weierstrass Approximation Theorem: given a continuous function $f(x)$ that is continuous on a given interval $[a, b]$, for each $\epsilon > 0$ there exists a polynomial $P(x)$ such that:
  \[
    |f(x) - P(x)| < \epsilon
  \]
\end{theorem*}

The proof of this theorem relies on either Bernstein Polynomials, Binomial Distributions or the Stone-Weierstrass Theorem~\cite{proofwiki-weierstrass_approximation}, so we'll skip it.

Polynomials are a particularly usefull mathematical objects because they are easy to integrate and differentiate, so they are often used to approximate functions.

\subsection{Lagrange Interpolating Polynomials}

The simplest case for interpolation is for $2$ points $(x_0, y_0), (x_1, y_1)$. So our goal is to find some polynomial function $f$ such that $f(x_0) = y_0$ and $f(x_1) = y_1$. Here's where the Lagrange polynomials:

\[
  L_0(x) = \frac{x - x_1}{x_0 - x_1}, L_1(x) = \frac{x - x_0}{x_0 - x_1}
\]

And the Lagrange interpolating polynomials:

\[
  P(x) = L_0f(x_0) + L_1f(x_1)
\]

Note that:

\begin{gather*}
    P(x_0) = y_0 \\
    P(x_1) = y_1
\end{gather*}

So $P(x)$ is indeed a polynomial that contains the desired points. Of course we want the formula to work for more than $2$ points, so we want a general structure for $n + 1$ points (a polynomial of degree $n$ has $n + 1$ degrees of freedom). So we want:

\[
  P(x_i) = y_i
\]

At all points. For this we want a collection of special coeficients of $y_0, y_1, \dots$ such that they are $1$ at the corresponding $x$ and $0$ otherwise:

\[
  L_i(x_j) =
  \begin{cases}
  1, j = i\\
  0, j \ne i
  \end{cases}
\]

Note that this structure is similar to a Kronecker delta function. The easiest way to build such polynomial is by the factorisation of the roots:

\[
  (x - x_0)(x - x_1)(x - x_2)\dots(x - x_n)
\]

But of course this polynomial does not yield only the zeros and ones nescessarily, so we normalize them:

\[
  L_i(x) = \prod_{i \ne j} \frac{x - x_j}{x_i - x_j}
\]

We have to exclude $i = j$ to avoid division by zero. Now we can get the terms together:

\[
  P(x) = \sum_{i = 0}^n y_i \prod_{i \ne j} \frac{x - x_j}{x_i - x_j}
\]

\begin{equation}\label{eq:lagrange_interpolation_formula}
  P(x) = L_0f(x_0) + L_1f(x_1) + \dots + L_nf(x_n)
\end{equation}

\subsection{Further Investigation of Lagrange Interpolating Polynomials}

There are a few interesting facts about this formula. Notably, we saw that $L_i(x_j)$ acts similarly to a Kronecker delta. Indeed, when $x$ is equal to any $x_i$ we get $L_i = 1$ and all other $L_{j \ne i} = 0$ leaving the polynomial as

\[
  P(x) = f(x_i)
\]

Which is exactly what we want. Moreover, one can ensure that

\[
  \sum_{i = 0}^n L_i(x) = 1
\]

\begin{proof}
Let $Q(x) = \sum_{i = 0}^n L_i(x)$, if $x$ is any $x_i$ we have $Q(x_i) = 1$ as $L_i(x_j)$ behaves as a Kronecker delta. So we have that

\[
  Q(x_0) = Q(x_1) = \dots = Q(x_n) = 1
\]

So $Q$ is a polynomial of degree at most $n$ (by definition of $L_i$) and agrees on $n + 1$ points with the constant polynomial $R(x) = 1$. So by the Fundamental Theorem of Algebra $R(x) = Q(x)$.
\end{proof}

This fact shows some interesting proprties of interpolation:
\begin{enumerate}
        \item Constants stay constant: if $y_0 = y_1 = \dots = C$ then $P(x) = \sum_i y_iL_i(x) = C \sum_iL_i(x) = C$
        \item Translation invariance: if a constant $+ C$ is added to the function, for a new output point $z_z$ defined as $y_i = y_i + C$, then the new polynomial $G(x)$ is defined as $G(x) = \sum_i y_iL_i(x) + C\sum_iL_i(x) = P(x) + C$
        \item A collection of functions ${f_i(x)}$ that satisfies $\sum_i f_i(x) = 1$ is called a ``partition of unity''. It has multiple aplications in computer science, specially computer graphics for blending colors and geometry. So this idea is deeper than just this one method.
\end{enumerate}

\subsection{Error Analysis}\label{sec:error}

Unlike root-finding algorithms, the interpolation ones do not take an $\epsilon$ as input, hence we need to calculate an error by hand.

The error term for the approximation $P(x)$ of $f$ (assuming $f \in C^{n + 1}[a, b]$) using $n$ data points is defined as:

\[
  E_l(x) = \frac{f^{(n + 1)}(\xi(x))}{(n + 1)!}(x - x_0)(x - x_1)\dots(x - x_n)
\]

Notice that it is almost the same as the error term for Taylor's expasion:

\[
  E_t(x) = \frac{f^{(n + 1)}(\xi(x))}{(n + 1)!}(x - x_0)^{n + 1}
\]

The proof for this relies on the Generalized Rolle's Theorem and the discussion about the amount of roots.

\begin{proof}
  If $x$ is any of the given $x_i$ points then the error will be zero as expected. Consider now that $x \ne x_i$, we define
  \[
    E(x) = f(x) - P_n(x)
  \]
  It's trivial to see that $E(x)$ has $n + 1$ roots (there are $n + 1$ given data points), so we can define one of the roots of the error as
  \[
    w(t) = \prod_{i = 0}^n (t - x_i)
  \]
  From where we can define a function $g(t)$ with this term
  \[
    g(t) = f(t) - P_n(t) Cw(t)
  \]
  If we choose a $C$ such that $g(t) = 0$, so $C = \frac{E(t)}{w(t)}$, moreover, we have $g(x_i) = 0$ and $w(x_i) = 0$, so $g$ has $n + 2$ roots:
  \[
    x_0, x_1, \dots, x_n, t
  \]
  Now assuming that $f \in C^{n + 1}$, Rolle's theorem ensures that $g'$ has at least $n + 1$ roots, and $g''$ has $n$ roots, and so on. Hence there exists one $\xi$ such that
  \[
    g^{n + 1}(\xi) = 0
  \]
  This derivative is
  \[
    g^{n + 1}(\xi) = f^{x + 1}(\xi) - P_n^{n + 1}(\xi) - Cw^{n + 1}(\xi)
  \]
  But $P_n$ has at most degree $n$ to $P_n^{n + 1}(\xi) = 0$, and $w(\xi)$ is a monic polynomial (that is, the coeficient of the highest nonzero term is 1), so it's $n + 1$ derivative is $(n + 1)!$. Lastly, we know $g^{n + 1}(\xi) = 0$, therefore the equation becomes
  \begin{gather*}
    f^{x + 1}(\xi) - C(n + 1)! = 0 \\
    C = \frac{f^{x + 1}(\xi)}{(n + 1)!}
  \end{gather*}
  Now recalling our definition of $C$ as $\frac{E(t)}{w(t)}$, we can now use $t = x$ and expand $w$ to get the formula
  \begin{gather*}
    \frac{E(x)}{w(x)} = \frac{f^{x + 1}(\xi)}{(n + 1)!} \\
    E(x) = \frac{f^{x + 1}(\xi)}{(n + 1)!} \prod_{i = 0}^n (x - x_i)
  \end{gather*}
\end{proof}

\subsection{Convergence Rate}

The convergence rate of polynomial interpolation depends on both the smoothness of the interpolated function and the choice of interpolation points, so it's not trivial to define a rate of convergence for this method. Specifically, there is a phenomenon in Numerical Analysis called Runge's phenomenon, which states that polynimal interpolation on equidistant points causes ocilations at the edges of the interval. Runge's phenomenon is not guaranteed to happen, but it's frequent enough to call it one of the problems in polynomial interpolation. Furthermore, higher degree interpolations are not certain to increase accuracy (this will latter lead us to Neville's method).

There are strategies to mitigate this issue such as using Chebyshev nodes, but that's beyond the scope of this analysis.

\section{Analysis of the Algorithm}\label{sec:analysis}

The good thing about an algorithm so simple is that we can get the exact amount of mathematical operations used to calculate it. As the inputs will be the data points ($xs$ and $ys$ of length $n$) and the point of interest $x$ we can calculate as a function of $n$: we have $n + 1$ outer terms, with $n$ factors each (since we skip $i = j$), each factor does $2$ subtractions and $1$ division, so $3n(n + 1)$. Then we multiply $n$ factors for each $1$: $n(n + 1)$, multiply them for another $n + 1$ operations and sum the $n + 1$ tems for $n$ additions, in total:

\[
  3n(n + 1) + n(n + 1) + n + 1 + n = 4n^2 + 6n + 1
\]

\section{Implementation}\label{sec:implementation}

For the language of choice implementing numerical methods we will use GNU Octave~\cite{octave}. The source code can be found in the GitHub repository ``numerical\_methods''~\cite{repo}, along with the sources of the analysis papers and other methods.

The implementation follows the algorithm described in Section~\ref{sec:algorithm}. The algorithm is so simple that one could actually write the entire code in one line, but that would obviously obfuscate the code for no reason. So the code is split into ``lagrange'' and ``L'' for clarity. One detail is that our formula is ``0-indexed'' but GNU Octave is ``1-indexed'', so our ranges are $[1, \rho(xs)]$ instead of the tipical $[0, \rho(xs))$.

\section{Conclusion and Discussion}\label{sec:conlusion}

Since its computational cost is predictable and it provides sufficient accuracy, Lagrange interpolation is well-suited to real-time applications. Moreover, it's simple to implement and provides a great theoretical basis for other, more complex interpolation methods such as spline interpolation.
